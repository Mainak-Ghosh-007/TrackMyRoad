# RoadWatch AI

RoadWatch AI is an AI-powered road infrastructure transparency platform that enables citizens to monitor road quality, track public spending, access maintenance records, and report road-related issues to the responsible authorities.

## Features

* Road quality monitoring
* Road project and contractor information
* Budget transparency and spending tracking
* AI-powered road information assistant
* Smart complaint generation and routing
* Community issue reporting and upvoting
* Offline functionality with local storage support
* Location-based road information lookup

## Technology Stack

### Frontend

* React 18
* TypeScript
* Vite
* Tailwind CSS
* Lucide React

### Backend

* Node.js
* Express.js
* TypeScript
* esbuild
* Vite Middleware

### AI Integration

* Gemini 2.5 Flash
* @google/genai SDK

### Storage

* Browser Local Storage for offline support

## Architecture

The application follows a full-stack TypeScript architecture where the React frontend communicates with an Express backend through REST APIs. Gemini AI powers intelligent road information retrieval, complaint drafting, authority identification, and contextual assistance.

## Objective

RoadWatch AI improves transparency, accountability, and citizen participation in road infrastructure management by making road project information accessible and actionable.
